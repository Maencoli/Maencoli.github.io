# 2027 달력 예약 → 구글 시트 연결

`reserve.html` 예약 폼 응답을 구글 시트에 한 줄씩 쌓는 앱스크립트예요.
**꼭 0h.miinah@gmail.com 계정으로 로그인한 상태에서** 진행하세요.
(브라우저에 여러 계정이 로그인돼 있으면 배포가 꼬이기 쉬우니, 시크릿 창에서 그 계정 하나만 로그인하는 걸 추천해요.)

## 1. 시트 만들기
1. https://sheets.new 접속 → 새 스프레드시트 생성
2. 제목을 `2027 달력 예약` 정도로 바꾸기

## 2. 스크립트 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script**
2. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여넣기
3. 💾 저장

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정
   - 다음 사용자 인증 정보로 실행: **나 (0h.miinah@gmail.com)**
   - 액세스 권한이 있는 사용자: **모든 사용자**  ← 이래야 사이트 방문자가 보낼 수 있어요
4. **배포** → 권한 승인 창이 뜨면 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → 허용
   (내가 만든 스크립트라서 뜨는 경고예요)
5. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/..../exec`) 복사

## 4. 사이트에 주소 넣기
`reserve.html`에서 아래 줄의 따옴표 안에 복사한 URL을 넣으면 끝이에요.

```js
const FORM_ENDPOINT = '';
```

(URL을 알려주시면 Claude가 넣어서 푸시해도 돼요.)

## 확인
- 웹 앱 URL을 브라우저로 열면 `{"ok":true,...}` 가 보여야 해요.
- 사이트에서 예약을 한 번 넣어보면 시트에 `예약` 탭이 생기고 한 줄이 추가돼요.

## 나중에 스크립트를 고쳤다면
**배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포** 로 다시 배포해야 반영돼요.
(이렇게 하면 URL은 그대로 유지돼요. "새 배포"를 누르면 URL이 바뀌니 주의!)
